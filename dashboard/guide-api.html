Panduan API Key Binance
Ikuti langkah berikut untuk menghubungkan akun Binance kamu ke Vyora Bot
⚠️ PENTING: Jangan pernah aktifkan permission "Enable Withdrawals". Vyora hanya butuh akses trading, bukan penarikan dana.
🔒 API key kamu disimpan terenkripsi dan hanya digunakan untuk eksekusi trading otomatis di akun Binance kamu sendiri.
1
Login ke Binance
Buka aplikasi Binance atau website binance.com dan login ke akun kamu. Pastikan akun sudah terverifikasi (KYC Level 1 minimal).
2
Buka API Management
Tap foto profil kamu di pojok kanan atas → pilih Profile → scroll ke bawah → tap API Management.

Atau langsung buka: binance.com/en/my/settings/api-management
3
Buat API Key Baru
Klik tombol Create API → pilih System generated → masukkan label "Vyora Bot" → klik Next.

Selesaikan verifikasi keamanan yang diminta (email/SMS/authenticator).
4
Atur Permission API Key
Aktifkan permission berikut dengan tepat:
PermissionStatusKeterangan
Enable Reading ✅ AKTIFKAN Baca data akun & harga
Enable Spot & Margin Trading ✅ AKTIFKAN Eksekusi order beli/jual
Enable Futures ❌ JANGAN Tidak diperlukan (kecuali paket Elite)
Enable Withdrawals ❌ JANGAN Demi keamanan dana kamu
5
IP Restriction (Opsional tapi Recommended)
Untuk keamanan ekstra, aktifkan Restrict access to trusted IPs only dan tambahkan IP server Vyora berikut:
IP Server Vyora
152.42.248.130
Jika tidak mengaktifkan IP restriction, API key tetap bisa digunakan namun kurang aman.
6
Simpan API Key & Secret
Setelah dibuat, Binance akan menampilkan API Key dan Secret Key.

⚠️ Secret Key hanya ditampilkan SEKALI! Simpan dengan aman sebelum menutup halaman.

Copy kedua key tersebut dan masukkan ke halaman Settings Vyora.
7
Input ke Vyora Settings
Buka halaman Settings → masukkan API Key dan Secret Key → klik Simpan.

Tim Vyora akan memverifikasi dan mengaktifkan bot kamu dalam 1x24 jam setelah pembayaran dikonfirmasi.
FAQ
Apakah dana saya aman?
Ya! Vyora hanya bisa melakukan trading (beli/jual), tidak bisa menarik dana. API key tanpa permission Withdraw tidak bisa digunakan untuk mencuri dana kamu.
Berapa modal minimum?
Minimum $10 USDT di akun Binance Spot. Rekomendasi $50-$100 USDT untuk hasil optimal.
Bot trading pair apa saja?
Saat ini bot fokus pada BTC/USDT dengan strategi EMA+RSI+MACD+BB dan konfirmasi AI. Pair lain akan ditambahkan di update berikutnya.
Bagaimana cara menghubungi support?
Hubungi tim Vyora via WhatsApp atau email yang tertera di halaman billing untuk bantuan aktivasi dan pertanyaan teknis.
Siap Mulai Trading Otomatis?
Setelah API key siap, masukkan ke Settings dan tim kami akan mengaktifkan bot kamu segera.
